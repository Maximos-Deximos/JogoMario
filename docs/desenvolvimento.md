# Como contribuir

clone o repositório
```text
git clone https://github.com/Maximos-Deximos/JogoMario
```

# Branches

- `main` — código estável
- `dev/` — código de desenvolvimento

## Commits

Usamos Conventional Commits:

exemplo:
```text
feat (ou add): adiciona login
fix: corrige validação de usuário
docs: atualiza documentação
```
