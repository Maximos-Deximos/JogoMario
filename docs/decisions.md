## Documentação das decisões realizadas pelo projeto

Não entra dentro do escopo do projeto o uso da ferramenta node
A sua adição seria desnecessária e iria aritificalmente inflar o tamanho do projeto sem adicionar
Nenhuma susbtancia relevante em seu processo de desenvolvimento ou execução.

- O projeto não precisa de um node para ser executado
- O projeto pode ser executado diretamente a partir do arquivo .html
- A adição de node pode comprometer o interece de qualquer usuario que deseja jogar o "jogo"

## Mesmo assim node será adicionado somente para aderir as regras do projeto

Nenhuma menção de node será feita no arquivo README.md
